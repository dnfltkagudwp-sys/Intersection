# Claude 작업 지시 템플릿

다른 Claude에게 작업을 보낼 때 아래 형식을 매번 복사해 채운다. 재시도·후속 수정에도 컨텍스트 제한 블록을 다시 넣는다.

```text
[컨텍스트 제한]
- 먼저 `Docs/작업인계.md`의 “현재 상태/다음 작업”만 읽어라.
- 이 작업에서 읽어도 되는 문서/범위: <문서명 + 절/줄 범위. 없으면 “없음”>
- `Docs/GameDesign.md`, 다른 제작 원고, `Docs/History`, 전체 로그는 통째로 읽지 마라.
- 필요한 내용은 `rg -n`과 지정 줄 범위로만 확인하라.
- 현재 작업 범위를 넓히지 마라.

[목표]
<이번 한 작업의 결과>

[허용 범위]
- 읽기: <파일/디렉터리>
- 수정: <파일/디렉터리>

[금지]
- <건드리면 안 되는 진행 중 변경과 기능>
- 관련 없는 리팩터링·문서 정리·에셋 재생성

[완료 조건]
- <관찰 가능한 결과>
- <호환성·회귀 조건>

[검증]
- <이번 변경에 필요한 최소 명령/Unity 메뉴/플레이 경로>
- 실제 키보드·마우스·게임패드 입력과 창 포커스 검수는 사용자 담당이므로 지시·완료 조건에서 제외
- 전체 로그를 출력하지 말고 오류 검색과 마지막 100~200줄만 확인

[보고]
- 바꾼 파일, 검증 결과, 남은 문제만 짧게 보고
```

문서 범위 예시: `Docs/교차점_P4_정식콘텐츠_원고_v0.1.md 16절 1번과 그 항목이 참조한 2-3절만`. “P4 문서”처럼 범위를 넓게 쓰지 않는다.
