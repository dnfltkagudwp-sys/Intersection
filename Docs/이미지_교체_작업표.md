# 이미지 교체 작업표

이미지 제작자가 주말에 자산을 교체할 때 사용할 작업표다. 콘텐츠 ID·파일명·검색 조건은 바꾸지 않고, 기존 이미지 파일의 내용만 교체하는 것을 기본으로 한다.

## 실행 범위

이 문서만 작업 지시로 받아도 아래 범위는 그대로 진행할 수 있다.

- 허용: 이 문서에 적힌 사진·캡처 이미지 교체, 브라우저·지도 미리보기 신규 제작과 `preview` 연결, 교체된 원본으로 캡처 재렌더링.
- 금지: 콘텐츠 ID, 파일 표시명, 기록 시각, 글자 원문, 검색어, 접근 단계, 진행 조건, 수량 변경. 이미지 작업을 이유로 사건 설명이나 새 단서를 추가하지 않는다.
  - 예외(2026-10-18 사진 피해·게시 맥락 수정 확정안): A08 지정 메시지 2건, A06-02·A06-05·D01-04 게시글 본문, P4-B13-C3 레이어 표시와 그 번역·전사본·캡처 문구만 확정안대로 바꾼다. 그에 따른 일반 텍스트 검색 결과 변화는 허용한다.
- 기존 작업과 무관한 변경 및 폰트 SDF 변경은 보존하되 커밋에서 제외한다.
- 실제 키보드·마우스 입력 검수는 하지 않는다. 이미지 연결, 확대 표시, 잘림, 콘텐츠 검증까지만 확인한다.
- 이미지 생성·편집 수단이 없거나 동일 인물의 연속성을 지킬 참조가 없으면 임시 대체물을 만들지 말고 해당 행을 `사용자 원본 필요`로 남긴다.
- 이 문서의 가림 스티커 규칙은 P2·P4 원고에 남은 과거 스티커 좌표·크기보다 우선한다. 다른 콘텐츠 규칙은 원고를 유지한다.

## 공통 원칙

- 사진 한 장의 자극성보다 `원본 → 대상 분리 → 맥락 제거·가림 → 게시용 결과물`의 연속성이 먼저 읽혀야 한다.
- 노골적인 성적 이미지는 제작하거나 표시하지 않는다. 정유진 최종본에는 `성적 합성 이미지 / 내용 가림` 열람 안내를 두고, A06-02에서 게시자의 자발적 전송 주장과 `noon_27`의 합성 부인·삭제 요구 댓글을 함께 보여 피해의 성격을 전달한다. A08 대화도 유지한다. 피해의 종류를 숨겨서 추리 난도를 만들지 않는다.
- 이미지 비교는 원본의 출처와 가공 과정을, 게시물과 대화는 동의 없는 이용·허위 설명·삭제 요구 무시·재게시를, 복구 파일과 계정 기록은 제작·게시 주체와의 연결을 담당한다. 크롭·얼굴 가림·압축·편집 파일의 존재만으로 악의성을 확정하지 않는다.
- 비교 단서는 단계별로 구분한다. C의 B07↔B08에서는 셔츠 주름·소매 자수·스티커와 배경을, B08↔최종 게시본에서는 가림 밖 머리·스티커 위치와 주변 머리·상단 배경·추가 크롭 관계를 비교한다. 최종본의 옷·자수·손은 가려져 보이지 않는다. D·E 계열의 원본·파생본 기준은 유지한다.
- 얼굴 스티커는 게시자의 반복 편집 습관으로 유지한다. 민감한 영역을 표시하지 않기 위한 불투명 가림과 구분하며, 어느 가림도 그 자체로 범죄의 증거처럼 취급하지 않는다. 얼굴 없는 사진에는 얼굴 스티커를 붙이지 않는다.
- 민감한 부분 아래에 실제 성적 합성물을 만들 필요는 없다. 안전한 일상사진의 식별 가능한 일부와 불투명 가림으로 최종 표시 자산을 제작한다. 가림 제거·복원·확대를 통해 숨긴 부분을 볼 수 있게 하지 않는다.
- 이미지 안에 긴 설명을 넣지 않는다. 플레이어가 원본과 편집본을 나란히 보고 판단할 수 있어야 한다.
- 한국어·영어 공용으로 쓸 화면은 글자를 최소화한다. 꼭 필요한 글자는 게임 UI가 별도로 표시하는 제목·시간에 맡긴다.
- 가능하면 기존 파일을 같은 이름으로 덮어써서 연결과 검색 회귀를 보존한다. 새 파일을 쓰는 경우에만 해당 레코드의 `preview` 또는 `image`에 다시 연결한다.

### 가림 스티커 규칙

- 스티커는 실제로 보이는 얼굴을 익명화할 때만 사용한다. 얼굴이 없거나 뒷머리만 보이는 사진에는 붙이지 않는다.
- 크기는 얼굴 윤곽의 약 1.15~1.3배로 제한한다. 머리카락·목·상체까지 크게 덮지 않는다.
- 같은 크림색 스마일 모양은 계정의 반복 편집 습관을 보여주는 단서로 유지하되, 모든 사진에서 같은 화면 비율로 키우지 않는다.
- 범죄성은 스티커 크기가 아니라 무단 촬영, 표적만 남긴 크롭, 반복된 편집 계보와 게시 문맥으로 보여준다.
- P2에서 원본 연결을 어렵게 해야 하는 이미지는 거대한 스티커 대신 좁은 크롭, 낮은 밝기, 강한 압축과 주변 인물의 일부로 모호하게 만든다.

대상: `Assets/Art/Photos/Originals/A_IMG_5821.png`부터 `A_IMG_5919.png`까지의 사건 사진.

- 같은 인물이 여러 날에 걸쳐 멀리서 찍혔다는 사실이 먼저 보여야 한다.

- 날짜 구역이 이미 화면에 표시되므로 이미지 안에 날짜나 `사망 N일 전` 문구를 넣지 않는다.
