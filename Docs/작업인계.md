## 남은 별도 항목

- A01 사진 18장은 현재처럼 일반 `최근 항목`에 섞어 두고 `윤서하`·`추적` 같은 설명적 수동 앨범은 만들지 않는다. 다만 개별 사진이 여자친구를 찍은 자연스러운 사진처럼 읽힐 수 있으므로, 후속 UI 검토에서 날짜별 구분선으로 6일간 반복 촬영(하루 3장)의 누적을 한눈에 보이게 할지 확인한다. 필요하면 너무 깨끗한 구도의 일부만 원거리·가림·줌 흔적이 더 느껴지도록 조정한다. 현재 P4 작업과는 별도이며 지금 구현하지 않는다.
- P2의 D01-05 이미지는 정식 자산이다(2026-10-15). B06 → P4-B13-D2 `r0786_a` → D4 `r0786_f2` 계보로 다시 렌더링했고 `derivedFrom`은 D4다. 남은 6번 항목은 A06-05 캡처 원본 교체(결정 10)다.
- 영어 미번역 17키는 P2 글자 포함 캡처 전사본이다. A06·D01 영문 이미지와 언어별 미리보기를 다시 렌더링할 때 함께 처리한다.
- 1366×768 휴대전화 상단 제목은 폭이 좁아 말줄임된다. P4와 무관한 별도 UI 작업이다.
- 캡처 UI 후처리 밝기와 작은 본문 글자, 긴 파일명 말줄임은 별도 시각 검수 대상으로 남아 있다.
