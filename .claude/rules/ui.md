# UI 규칙

- 메인 UI 레이아웃의 원본은 `Assets/Scripts/Editor/MainUIBuilder.cs`다. 씬·프리팹 수작업 변경은 빌더에도 반영한다.
- 빌더 재실행은 UI 루트와 프리팹을 다시 만들 수 있으므로 UI 구조 변경에만 사용하고 데이터 에셋 변경과 섞지 않는다.
- 표시 문구를 코드에 하드코딩하지 않고 문자열 테이블과 `UIText`를 쓴다.
- 사용자 용어는 `작업함`, `고정`, `보존`, `삭제 후보`를 유지한다. 저장 필드의 옛 이름은 호환 때문에 그대로 둘 수 있다.
- 작업함·비교·휴대전화 사이를 오갈 때 선택, 필터, 스크롤, 우측 패널 상태를 불필요하게 초기화하지 않는다.
- 1920×1080과 1366×768에서 겹침·잘림·스크롤·말줄임을 확인한다.
- 사용자가 지정하지 않은 레이아웃 개선을 같은 작업에 끼워 넣지 않는다.
